# iPhone Shortcut: Daily Market Intelligence

The Shortcut opens the permanent Pages alias; it does not download or retain
report files on the phone. The default report is generated from free official
feeds; the iPhone needs no OpenAI app, API key, account, or billing setup.

1. Open **Shortcuts** on the iPhone.
2. Tap **+** and name the Shortcut `Daily Market Intelligence`.
3. Add the **URL** action.
4. Paste this permanent report URL:
   [https://changfanghan0324.github.io/us-market-intelligence/latest.html](https://changfanghan0324.github.io/us-market-intelligence/latest.html)
5. Add the **Open URLs** action.
6. Tap **Done**.
7. Optional: use the Shortcut details menu to add it to the Home Screen.

The report header prominently shows its report date and generation time. If those
are stale, check the repository's latest workflow run before relying on it. An
open-day Earnings panel labeled `data_unavailable` is an expected free-source
limitation—not a statement that no company reports that day. The permanent URL,
eight-report retention policy, and one-tap behavior are unchanged.
